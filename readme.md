Exercise 1
Reimplement functions testSquare and twice by using the dot operator and dropping the
second arguments (have a look at the implementation of squareTimes2 to get an idea where
this should lead you). This highly concise way of writing function implementations is sometimes
called point-free style and is often the preferred way of writing small utility functions.
